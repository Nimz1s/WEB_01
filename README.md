# WEB_01# TableBook

TableBook — вебзастосунок для бронювання столиків у ресторанах.

## Технології

- Node.js
- Express.js
- PostgreSQL
- Prisma ORM
- Socket.io
- JWT Authentication
- Swagger
- Zod

## Вимоги

- Node.js
- PostgreSQL
- npm

## Встановлення

Клонуйте репозиторій та перейдіть до папки проєкту:

```bash
git clone https://github.com/Nimz1s/WEB_01.git
cd WEB_01
npm install
```

## Налаштування середовища

Створіть файл `.env` у корені проєкту на основі `.env.example`.

Заповніть змінні середовища власними значеннями, зокрема підключенням до PostgreSQL та JWT-секретами.

Не публікуйте `.env` і справжні секрети в репозиторії.

## База даних

Застосуйте міграції Prisma:

```bash
npx prisma migrate deploy
```

Згенеруйте Prisma Client:

```bash
npx prisma generate
```

## Запуск

Режим розробки:

```bash
npm run dev
```

Звичайний запуск:

```bash
npm start
```

## API та документація

API доступне за адресою:

`http://localhost:3000`

Swagger UI:

`http://localhost:3000/api-docs`

## Основні можливості

- Реєстрація та авторизація користувачів через JWT.
- Ролі користувачів і контроль доступу.
- Управління ресторанами та столиками.
- Створення й управління бронюваннями.
- Персональні сповіщення.
- Реальний час через Socket.io.
- Відстеження онлайн-статусу користувачів.
- Документація API через Swagger.

## Socket.io

Socket.io використовується для:
- повідомлень про нові бронювання;
- оновлення статусів бронювань;
- персональних сповіщень;
- відстеження онлайн-статусу користувачів.

Для підключення клієнт повинен передати JWT
