# Звіт з лабораторної роботи №2

**Тема роботи: Аутентифікація, авторизація та розширений функціонал backend-системи TableBook**

Здобувач освіти: Вознюк Ілля Сергійович 
Група: ІПЗ-41   
## Мета роботи

Реалізувати систему автентифікації та авторизації користувачів, захист API за допомогою JWT, безпечне зберігання паролів, керування сесіями, завантаження файлів, пошук, фільтрацію, пагінацію та документацію API.

## Виконання роботи

### 1. Налаштування проєкту

- Використано наявний backend-проєкт TableBook.
- Встановлено необхідні залежності для автентифікації, валідації та роботи з файлами.
- Налаштовано змінні середовища у файлі `.env`.
- Використано CommonJS для організації модулів Node.js.
- Налаштовано конфігурацію Express.js.

### 2. Автентифікація користувачів

- Реалізовано реєстрацію користувачів.
- Додано валідацію вхідних даних за допомогою Zod.
- Реалізовано хешування паролів за алгоритмом Argon2id.
- Реалізовано перевірку пароля під час входу.
- Налаштовано генерацію Access Token та Refresh Token за допомогою JWT.
- Реалізовано оновлення токенів із ротацією Refresh Token.
- Реалізовано відкликання Refresh Token під час виходу користувача.

### 3. Авторизація та захист API

- Створено middleware для перевірки JWT.
- Реалізовано middleware для перевірки ролей користувачів.
- Налаштовано такі ролі: `CUSTOMER`, `RESTAURANT_ADMIN`, `SYSTEM_ADMIN`.
- Реалізовано захищений endpoint для отримання інформації про поточного користувача.
- Реалізовано endpoint для перевірки доступу системного адміністратора.

### 4. Робота з файлами

- Реалізовано завантаження зображень ресторанів за допомогою Multer.
- Додано перевірку типів файлів: JPG, PNG, WEBP.
- Встановлено максимальний розмір файлу — 5 МБ.
- Реалізовано генерацію унікальних назв файлів.
- Налаштовано збереження зображень у папці `uploads`.
- Реалізовано видалення зображень із файлової системи.
- Реалізовано оновлення поля `imageUrl` у базі даних.

### 5. Пошук, фільтрація та пагінація

- Реалізовано пошук ресторанів за назвою.
- Додано фільтрацію ресторанів за містом (адресою).
- Реалізовано пагінацію результатів.
- Додано параметри `page` та `limit`.
- Реалізовано обмеження максимальної кількості результатів на сторінці.
- Додано інформацію про загальну кількість результатів і кількість сторінок.

### 6. Документація API

- Налаштовано Swagger UI.
- Додано документацію для endpoint-ів автентифікації.
- Додано документацію для роботи з ресторанами та столиками.
- Налаштовано Bearer Authentication для JWT.
- Додано опис параметрів пошуку, фільтрації та пагінації.
- Додано документацію для завантаження та видалення зображень.

## API endpoints

### Автентифікація та авторизація

| Метод | Endpoint | Призначення |
|---|---|---|
| POST | `/api/auth/register` | Реєстрація користувача |
| POST | `/api/auth/login` | Вхід користувача |
| POST | `/api/auth/refresh` | Оновлення токенів |
| POST | `/api/auth/logout` | Вихід та відкликання Refresh Token |
| GET | `/api/auth/me` | Отримання інформації про поточного користувача |
| GET | `/api/auth/admin` | Перевірка доступу системного адміністратора |

### Робота з ресторанами

| Метод | Endpoint | Призначення |
|---|---|---|
| GET | `/api/restaurants` | Отримання списку ресторанів |
| POST | `/api/restaurants` | Створення ресторану |
| GET | `/api/restaurants/{id}` | Отримання ресторану за ID |
| PUT | `/api/restaurants/{id}` | Оновлення ресторану |
| DELETE | `/api/restaurants/{id}` | Видалення ресторану |
| POST | `/api/restaurants/{id}/image` | Завантаження зображення |
| DELETE | `/api/restaurants/{id}/image` | Видалення зображення |

Для отримання списку ресторанів підтримуються параметри:
- `search` — пошук за назвою;
- `city` — фільтрація за адресою;
- `page` — номер сторінки;
- `limit` — кількість результатів на сторінці.

### Робота зі столиками

| Метод | Endpoint | Призначення |
|---|---|---|
| GET | `/api/tables` | Отримання всіх столиків |
| POST | `/api/tables` | Створення столика |
| GET | `/api/tables/{id}` | Отримання столика за ID |
| PUT | `/api/tables/{id}` | Оновлення столика |
| DELETE | `/api/tables/{id}` | Видалення столика |

## Висновки

Під час виконання лабораторної роботи №2 було розширено backend-систему TableBook та реалізовано основні механізми автентифікації й авторизації користувачів.
Було реалізовано безпечне хешування паролів за допомогою Argon2id, автентифікацію за допомогою JWT, керування Refresh Token, перевірку ролей користувачів, завантаження та видалення зображень ресторанів, а також пошук, фільтрацію та пагінацію.
Для зручності тестування та взаємодії з API налаштовано документацію Swagger із підтримкою Bearer Authentication.
У результаті роботи отримано розширену backend-систему TableBook із додатковими механізмами безпеки та керування даними.
